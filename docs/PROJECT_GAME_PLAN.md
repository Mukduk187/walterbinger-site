# WalterBinger.com Project Game Plan

Date: 2026-07-19

Purpose: keep Walter, Scout, Lumen, and future work threads coordinated. The project should advance through blueprint, source curation, drawing, prototype, and punch-list passes rather than jumping straight from metaphor to implementation.

## Roles

Walter:

- Owner, architect, taste authority, and final decision-maker.
- Supplies direct source material, corrections, approvals, and "that is not me" vetoes.

Scout:

- Exploratory design collaborator.
- Helps Walter sketch references, mood, visual metaphors, and possible scene art.
- Scout output is background signal until Walter explicitly approves it.

Lumen / Codex:

- Builder and systems translator.
- Implements only from approved directives, registries, and source packs.
- Must not turn style references into site sections without approval.

This thread:

- Coordination layer.
- Organizes source material, keeps the blueprint current, and translates design decisions into buildable instructions.

## Current Approved Direction

The primary visual foundation is the white, hand-drawn Magic Crayon direction:

- warm paper
- black linework
- generous negative space
- childish but careful marks
- color earned through attention
- Lite-Brite / carnival-light awakening
- Charlotte's Web relationship logic
- no dark tarot/celestial fantasy as the main interface

Core rule:

> Keep the drawings simple. Let interaction provide the complexity.

## Phase 3: Homepage Interaction Blueprint

Status: partly explored in draft prototypes; needs consolidation.

Approved mechanics:

- discoverable stars are larger and can twinkle/glow when active
- passive field stars stay graphite
- one lens = gravitational emphasis
- two lenses = possible blended orbit
- three or more lenses = relationship-weighted field, not arbitrary zodiac circle
- objects slide into position with a brief trail
- hover/focus should not reset animations
- mobile uses a tall scrollable universe

Needs documentation:

- exact lens list
- relationship weights
- star positions
- active/dormant/revealed/completed states
- reduced-motion behavior

## Phase 4: Prototype Repair

Status: wait until Phase 1-3 docs are consolidated.

The existing prototype work contains useful mechanics, but it is not the approved visual source of truth.

Keep:

- star/tattoo reveal logic
- active lens behavior where approved

Rework:

- remove overbuilt/dark/tarot instincts
