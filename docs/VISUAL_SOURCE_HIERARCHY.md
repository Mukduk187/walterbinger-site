# Visual Source Hierarchy

Date: 2026-07-19

Walter's direct rule is to curate from real material rather than manufacture arbitrary symbols. New artwork should remain traceable to a personal artifact, a historical structure, or a clearly named influence.

## Tier 1: Walter's source material

- drawings, menu art, logos, handwriting, notes, diagrams, photographs, sculptures, furniture, and installation work
- use directly when the artifact is appropriate and rights are clear
- preserve imperfections that carry authorship; do not polish them into generic icons

## Tier 2: historical structural material

- public-domain celestial atlases, engravings, maps, scientific diagrams, emblems, and planispheres
- use as scaffolding for composition, line behavior, ornament, or spatial systems
- record the source before adapting it

## Tier 3: aesthetic influence

- artists and traditions Walter values, including Keith Haring, tattoo flash, Shel Silverstein, observatory installations, and constellation drawing
- use as a compass for energy, density, movement, and restraint
- do not copy a living artist's identifiable work or pass stylistic imitation off as Walter's art

## Build rule

Every major navigational object should have a small source note before it becomes final. If no direct or historical source exists, collaborate with Walter on a new drawing rather than silently inventing a polished substitute.
