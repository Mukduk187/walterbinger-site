# 2026-07-19 Relative Universe Origin

This pass translates the map rule into behavior: the landing sky remains decentralized, but entering a world creates one local origin. The observable map then rearranges around that origin.

- In world mode, only the current world acts as the active root. Prior pins no longer create hidden second centers while traveling.
- Travel no longer automatically pins a star. Pinning is a landing-sky choice; entering a world is a spatial move.
- Healthcare's Libra scale now uses the focused star as the pivot/origin, not a side pan.
- Nearby, middle, and distant stars get quieter or stronger based on relationship score to the current origin.
- If a Healthcare-rooted view does not have enough related points to make the full scale, it falls back to a simple relationship path instead of disappearing into dots.
