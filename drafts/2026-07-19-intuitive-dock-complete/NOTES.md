# 2026-07-19 Intuitive Dock Complete

Reference snapshot for the completed pass after the "no explanatory text boxes" direction.

What changed:

- Landing starts with no active lenses and no carousel/dock.
- Explanatory note panel, go/clear controls, artifact preview card, world note copy, and large feature popup are visually removed.
- Single-click on a star pins/unpins that point.
- Double-click on a star teleports into that point.
- Healthcare lens reorients related stars into a Libra-scale constellation.
- The Healthcare scale uses real star points plus helper constellation dots to complete the drawing.
- World scenes keep the white/paper sky and show only the place title, background/margin line drawing, and bottom dock.
- Bottom artifact images now behave like a small Mac-style dock: icon-only, floating over the scene drawing, with hover magnification.
- A comet/streak element is attached to each star for hover exploration.
