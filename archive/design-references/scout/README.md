## Useful system ideas

- Interactive objects and non-clickable sky lore should be visibly different.
- Discoverable objects can move through dormant, hinted, and revealed states.
- A compact object should suggest an underlying form without becoming a fully legible logo at rest.
- Planets, moons, comets, nebulae, paths, and tiny objects can make the field richer without all becoming destinations.
- Curved guide paths and irregular celestial marks are a stronger direction than straight graph wiring.
