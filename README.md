# WalterBinger.com

Static first version of Walter Binger's personal professional site.

Current status: this repo is scaffolding, not the approved visual source of truth. The dark "Proof Room" direction and the later "custom business card" prototype should both be treated as rejected explorations.

The authority layer is `docs/WALTER_DIRECTIVES.md`. Follow Walter's direct commands and Walter-authored attachment guidance over Scout/ChatGPT commentary.

The current homepage mechanic is documented in `docs/HOMEPAGE_MECHANIC_NOTES.md`: a sparse star field that reveals flash-tattoo-like drawings, constellations, and worlds through attention.

## Files

- `index.html` contains the site content and sections.
- `styles.css` contains the responsive visual system.
- `script.js` powers the mobile menu and email-copy interaction.
- `assets/hero-systems-map.png` is the generated hero visual asset.
- `CNAME` points GitHub Pages to `walterbinger.com`.
- `docs/WALTER_DIRECTIVES.md` captures Walter's direct instructions and precedence over Scout/ChatGPT commentary.
- `docs/DESIGN_REVIEW_NOTES.md` captures the current design critique, resume translation, and next blueprint requirements.
- `docs/HOMEPAGE_MECHANIC_NOTES.md` captures the current homepage interaction direction.

## Publishing

This repo is ready for GitHub Pages from the repository root. The custom domain file is already present.

Before final public launch, replace `CONTACT_EMAIL` in `script.js` if the preferred inbox is not `hello@walterbinger.com`, and point the LinkedIn links to the final profile URL once confirmed.
